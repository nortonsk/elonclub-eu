# elonclub.eu

Static site of Elon Club z.s. (English), built with Jekyll and hosted on GitHub Pages.

- New post: add `_posts/YYYY-MM-DD-slug.md` with `title`, `date`, `author`, `categories` and optionally `image` (a path under `assets/img/`).
- Pages are Markdown files in the root (`meetups.md`, `contact.md`, ...); navigation and contact details live in `_config.yml`.
- Styles are in `assets/css/site.css`, templates in `_layouts/` and `_includes/`.

Every push to `main` is built and deployed by GitHub Pages automatically.
